## About

**UNBOXX Business** is an AI-powered platform that helps universities attract, engage, and convert prospective students — from first digital visit to confirmed enrollment.

This GitHub organization hosts all repositories powering the UNBOXX Business ecosystem.

---

## What We Build

- 🌍 Geo-optimized student discovery  
- 🧭 AI virtual campus tours  
- 🤖 Admissions automation  
- 📊 Enrollment analytics  
- 🔗 APIs & integrations  

Built for institutions that want measurable enrollment growth.

## Why UNBOXX

Universities lose students between  
**visit → inquiry → application → enrollment**

UNBOXX Business closes that gap using AI, automation, and data.
